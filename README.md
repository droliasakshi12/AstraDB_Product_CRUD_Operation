# 📊AstraDB Product CRUD

**AstraDB Product CRUD** is a Python application to demonstrate how to perform **CRUD (Create, Read, Update, Delete)** operations on a student database using **AstraDB** — a cloud-native, serverless Cassandra database platform. This project provides a simple and practical example for database interaction with Python and AstraDB APIs.

---

## 🚀 Features

- 🧑‍🎓 Create a new product record  
- 📖 View existing product records  
- ✏️ adding new product information
- 📝 Update previous product 
- 📌 Built using Python and AstraDB APIs

**# AstraDB Student CRUD**

**AstraDB Student CRUD** is a Python application to demonstrate how to perform **CRUD (Create, Read, Update, Delete)** operations on a student database using **AstraDB** — a cloud-native, serverless Cassandra database platform. This project provides a simple and practical example for database interaction with Python and AstraDB APIs.

---

## 🚀 Features

- 🧑‍🎓 Create a new student record  
- 📖 Read (list/display) existing student records  
- ✏️ Update student information  
- 🗑️ Delete student records  
- 📌 Built using Python and AstraDB APIs

## 🛠️ Installation
### **Clone this repository:**
   ```bash
   git clone https://github.com/droliasakshi12/AstraDB_Student_CRUD.git
```
### **Navigate into the project directory:**
``` bash
cd AstraDB_Student_CRUD
```
### ** Install depedencies **
``` bash
pip install -r requirements.txt
```

### **Create and Activate Environment**
**CREATE**
``` bash
python3 -m venv venv
```
**ACTIVATE**
``` bash
venv\Scripts\activate
```
